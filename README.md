## Interpretation

Raw streams and original failed/incomplete receipts are immutable. Explicit terminal sidecars mark
where an observational controller was stopped; they do not relabel a failed startup as successful.
Cold preparation and failed first candidates are not acceptance trials. A full-graph flag can become
true after an ordinary compiler rebuild: use hydration outcome/route/record counts and fullBuilds to
distinguish that from saved hydration. The first driver's raw fullHydration observation checked that
aggregate flag; the current driver calls it fullGraph. First-observed milestones have polling bounds;
detailed profile milestones are relative to onload and converted to the renderer clock in the summary.
Source and hydration lanes overlap. Renderer timer gaps begin at the first observation and are not
paint. Heap samples are unforced process samples, not retained memory or a proven peak. Do not derive
a native speedup percentage from the failed baseline or combine unlike completion paths/coverage.
